# Tibetan Language Learner

A React app for learning Tibetan through short stories, inspired by
amarahasa.com. Stories are shown in Tibetan script (བོད་ཡིག); click any
highlighted word for its Wylie transliteration, phonetic pronunciation, and
English meaning.

Source: https://github.com/billingsmoore/GreenGaruda2
